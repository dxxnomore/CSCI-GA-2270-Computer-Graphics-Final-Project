# HP5 PLUS packaging reference

The HP5 PLUS catalogue tile displays the front and right panels of an unmodified
scan of a real ILFORD HP5 PLUS 135 / 36-exposure carton. CSS frames the two panels;
the artwork and lettering are not generated or redrawn. The scan includes the
paper's original wear. The catalogue tile uses this artwork; the detail viewer
continues to be a conceptual 3D model.

- Scan: https://github.com/dekuNukem/Film-Packaging/blob/master/film_packaging/archive/00090_000.jpg
- Contributor recorded in the archive database: @recycling.film
- Archive record: index 90, standard white/green/black box, expiry August 2022.
- Product reference: https://www.ilfordphoto.ca/product/hp5-plus-35mm-36-exp/
