# 胶片资料馆 · 初版

独立静态网页，面向中文胶片摄影者。初版提供胶片目录、参数资料、可旋转的 3D 示意模型，以及包装、样片与精选经验的内容位置。

## 更新馆藏

编辑 `dist/films.json` 中的 `films` 数组。每条记录需要唯一的 `id`、名称、类型、ISO、画幅、冲洗方式和资料来源。照片与用户建议在获得授权和编辑确认后分别加入 `photos`、`tips`。

网页优先读取 GitHub `film-archive-prototype` 分支的 `data/films.json`；无法连接时读取本站的 `films.json`。这样在 GitHub 修改数据后，重新打开网页即可看到更新（GitHub CDN 可能有短暂缓存）。修改布局或 3D 场景仍需重新发布网站。

3D 包装是原创示意模型，不代表实际印刷包装。三款胶片参数分别依据生产商公开资料填写；目前没有展示用户样片、投稿建议或他人包装扫描。

## 本地查看

在 `dist` 目录启动任意静态文件服务器，然后打开 `index.html`。3D 模型的 Three.js 模块由固定版本的 CDN 提供，需要联网。
